#  Gaussian Mixture Models (GMM)

## 1. Motivation: Beyond K-Means

![](./img-embedding/gmmE.gif)


K-Means assumes:

* hard assignment (each point belongs to exactly one cluster)
* spherical clusters
* equal variance

But real-world data often looks like:

* overlapping clusters
* different shapes (elliptical)
* uncertainty in assignments

GMM addresses this by introducing a **probabilistic clustering model**.

---

## 2. The Core Idea

![](./img-embedding/gmm1.jpg)

Instead of saying:

> "this point belongs to cluster k"

we say:

> "this point belongs to cluster k with probability 0.73"

---

## 3. Model Definition

![](./img-embedding/gmmA.gif)


A Gaussian Mixture Model assumes:

$$
p(x) = \sum_{k=1}^{K} \pi_k  \mathcal{N}(x \mid \mu_k, \Sigma_k)
$$

Where:

* $K$ = number of components
* $\pi_k$ = mixture weights, $\sum_k \pi_k = 1$
* $\mu_k$ = mean of component $k$
* $\Sigma_k$ = covariance of component $k$

Each component is a Gaussian distribution.

This means:

> Data is generated by first choosing a cluster, then sampling from its Gaussian. 

---

## 4. Latent Variable View

Introduce hidden variable:

$$
z_i \in \{1, \dots, K\}
$$

* $z_i$ = which Gaussian generated $x_i$
* **not observed**

This makes GMM a **latent variable model**

---

## 5. Soft Assignment (Responsibilities)

![](./img-embedding/gmmB.gif)

We compute:

$$
\gamma_{ik} = P(z_i = k \mid x_i)
$$

This is called the **responsibility**.

$$
\gamma_{ik} =
\frac{\pi_k \mathcal{N}(x_i \mid \mu_k, \Sigma_k)}
{\sum_j \pi_j \mathcal{N}(x_i \mid \mu_j, \Sigma_j)}
$$

Interpretation:

* how much cluster $k$ "owns" point $x_i$ 

---

## 6. Comparison with K-Means

![](./img-embedding/gmmC.gif)


| Feature       | K-Means   | GMM                 |
| ------------- | --------- | ------------------- |
| Assignment    | Hard      | Soft                |
| Cluster shape | Spherical | Elliptical          |
| Output        | Centroids | Probabilistic model |

Important insight:

> K-Means is a **special case of GMM** with:

* equal covariance
* hard assignments


---

## 7. Applications


GMM is widely used for:

* clustering
* density estimation
* anomaly detection
* speech recognition (classic pipelines)

---

## 8. Conceptual Summary

![](./img-embedding/gmmD.gif)

GMM combines three key ideas:

1. **Mixture modeling**
   → multiple simple distributions

2. **Latent variables**
   → unknown cluster identity

---

## 9. One-Sentence Intuition

> GMM = “K-Means with uncertainty + full Gaussian geometry”
